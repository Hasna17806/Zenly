# 🌿 Zenly – Student Wellbeing Platform

Zenly is a full-stack student wellbeing platform designed to help students monitor their emotional well-being, improve focus, complete mood-based challenges, and connect with professional support.

## 🚀 Live Demo

https://zenly-1-frontend.onrender.com/ 

## ✨ Features

* Mood Tracking
* Focus Improvement Tools
* Daily Challenges
* Professional Support Section
* Responsive Design
* Secure Authentication
* REST API Integration

## 🛠️ Tech Stack

**Frontend**

* React.js
* JavaScript

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

**Design**

* Figma
